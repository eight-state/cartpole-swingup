FUTURE CAPSULE REQUIREMENTS

No n=15 capsule exists yet. A future result must earn its own claim.

A new capsule must include:

1. A complete source checkout with a locked uv environment.
2. An explicit plant, force boundary, integration rate, and success predicate.
3. Immutable numerical evidence and a machine-readable provenance record.
4. A verifier that distinguishes authority checks from live numerical replay.
5. Tests for hashes, paths, predicate behavior, and failure cases.
6. A release-host statement and CI that matches the supported host boundary.
7. Plain documentation that excludes hardware, robustness, and mathematical-proof claims unless separate evidence establishes them.
8. A manifest entry generated from the final imported bytes.

A future capsule can use shared root code during development. Its release must still freeze every dependency needed to verify the result.
