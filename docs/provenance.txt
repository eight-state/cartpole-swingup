PROVENANCE

The original standalone releases are preserved by immutable Git tags named legacy/n05-quintuple through legacy/n14-quattuordecuple. Each rung entry records the expected tag, source commit, and source tree.

The shared authority check requires every tag to resolve to its recorded commit and tree. Source files referenced by historical evidence are read directly from that tagged Git tree. They do not need duplicate copies on main.

Current rung directories contain only numerical assets needed by the shared verifier or public demonstration. Each nominal, witness, gate record, and proof payload keeps its recorded SHA-256 identity.

Historical perturbation records remain unchanged. A stale path, failed controller leg, or unavailable private commit stays visible as historical evidence instead of being rewritten.

n=13 retains the controller and composed-proof payloads needed for replay. n=14 retains its witness, expected metrics, manifests, provenance, and host-of-record verification. Their historical source closures remain available at the corresponding legacy tags.
