HOST SENSITIVITY

Git tags and file hashes are portable. Numerical replay can depend on the operating system, Python build, numerical libraries, and processor behavior.

The repository uses one lockfile with the numerical versions shared by the standalone releases. This removes dependency drift between rungs but does not make floating-point trajectories platform-independent.

CI runs n=5 through n=11 on Linux and n=12 through n=14 on Windows, matching their published release boundaries. A host-sensitive replay failure does not erase a passing tag and evidence audit, and an authority pass does not certify a trajectory on a different host.
